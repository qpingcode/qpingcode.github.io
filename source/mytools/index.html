MyTools 是一款类似 Raycast、Alfred 的 Windows 效率工具：用更小的内存占用和更快的响应速度，把应用、文件与常用操作汇聚到一个搜索框；还可以直接使用 AI，按自己的想法随时创建和修改插件。

01

GET STARTED

下载安装

从 GitHub Releases 获取官方版本。完整安装包适合大多数用户；便携版解压即用，但不支持应用内自动更新。

推荐

完整安装包

下载文件名以 -setup.exe 结尾的版本，按安装向导完成安装。

前往项目首页安装说明 →
便携

Portable

下载 -portable.zip，解压后运行 MyTools.Desktop.exe。

便携版不支持应用内 Velopack 自动更新。
  1. 1
    打开项目首页的安装说明

    前往 MyTools 项目首页 → Installation，根据表格选择 Stable 或 Beta。Stable 为稳定版；Beta 包含最新功能。

  2. 2
    运行安装程序

    由于安装包暂未启用 Authenticode 签名，Windows SmartScreen 可能阻止启动。确认安装包来自 qpingcode/MyTools 官方仓库后，点击“更多信息”，再点击“仍要运行”。

  3. 3
    找到托盘图标

    启动后 MyTools 常驻系统托盘。双击图标或按 Alt+Space 打开搜索。

02

KEEP CURRENT

检查更新

  1. 1
    打开托盘菜单

    在任务栏通知区域找到 MyTools 图标并右键。

  2. 2
    点击“检查更新”

    检测到新版本后，按界面提示下载并重启。

遇到 GitHub API rate limit？

GitHub 对匿名 API 请求通常有每小时 60 次的限制。进入 设置 → 常规 → 网络代理，填写可用的 HTTP/HTTPS 代理地址（如 http://127.0.0.1:7890），保存后重新检查。

05

PLUGIN CONTROL

插件设置

进入“设置 → 插件”，选择一个插件即可调整它的调用方式。下面四项决定插件在哪里出现、怎样快速打开。

设置项作用建议
热键 Hotkey

从任意窗口直接打开该插件。

避免与系统或其他软件热键冲突。
别名 Alias

输入别名后再按一个空格，即可进入该插件的专属搜索或详情页。例如输入 guid 进入 UUID 插件，再继续输入 10。

别名与参数之间必须保留空格；建议使用短而好记的字母组合。
启用 Enabled

控制插件是否加载和参与搜索。

暂时不用的插件可以关闭。
全局 Global

开启后，无需先输入别名，插件结果会直接混入全局搜索。

高频插件开启；低频插件关闭以减少干扰。
Alias 与 Global 的区别

Alias 是“明确进入某个插件”：输入别名并按空格，例如 guid 、calc ，就会进入对应插件的搜索或详情页。Global 是“让插件主动参与所有搜索”，无需输入别名。例如 UUID 默认别名为 guid 且不参与全局搜索；计算器别名为 calc，同时支持全局实时计算。

MOUSE GESTURES

鼠标手势

怎么使用

  1. 1
    开启功能

    进入“设置 → 手势”，打开“启用”，然后按提示重启。

  2. 2
    画出手势

    按住鼠标右键移动，画出已配置的轨迹。

  3. 3
    松开执行

    松开右键后，MyTools 执行绑定的键盘快捷键或鼠标操作。

怎么添加

  1. 1
    点击添加手势

    在手势列表中新建一项并录入轨迹。

  2. 2
    指定范围

    可设为全局，也可限定只在某些进程中生效。

  3. 3
    绑定操作

    设置要模拟的快捷键或鼠标按键，保存后测试。

演示建议

可以用“向左”模拟 Alt + Left 返回上一页，用“向右”模拟 Alt + Right 前进，并把生效进程限制为浏览器。

PLUGIN GUIDE

插件指南

从生成 UUID 到翻译文本，下面按实际操作演示常用插件。

07

IDENTIFIERS

UUID 生成器

输入guid→生成 1 个 UUID
输入guid 10→生成 10 个 UUID

UUID 插件默认别名是 guid。输入数字可批量生成，最多 1000 个；在更多操作中还可以切换标准、无连字符和大写格式。

为连续粘贴准备

生成多个 UUID 后按 Ctrl + K，选择“全部加入剪贴板历史”。随后可用剪贴板的连续粘贴功能依次使用它们。

08

CLIPBOARD

剪贴板历史

打开历史Ctrl + Shift + V
连续粘贴Ctrl + Alt + V
1

搜索并粘贴

打开剪贴板历史后输入关键字过滤；按 Enter 粘贴选中项，或用 Ctrl + 数字快速选中。

2

去掉格式粘贴

选中富文本内容，执行“纯文本粘贴”（默认操作热键 Ctrl + Enter），仅保留文字。

3

连续粘贴

每按一次连续粘贴热键，都会粘贴并移除最新一条记录。可用上一节批量生成的 UUID 演示。

连续粘贴会消耗记录

该操作按“最新优先”粘贴，并从历史中删除已粘贴项。重要内容请先确认已另行保存。

09

CALCULATE

计算器

全局实时计算

计算器已参与全局搜索，直接输入表达式即可看到结果，无需先进入插件。

输入1231+123132=124363

查看计算历史

输入别名 calc 进入计算器，再查看之前的计算记录。选中结果可复制到剪贴板。

输入calc→历史列表
10

BROWSER DATA

搜索书签和历史记录

“书签与历史记录”插件支持 Chrome、Edge 和 Firefox。启用后，书签和访问记录会直接出现在全局搜索结果中。

  1. 1
    搜索书签

    唤起 MyTools，输入书签标题或网址中的关键字，结果副标题会标注浏览器和“书签”。

  2. 2
    搜索历史

    输入最近访问页面的标题或地址，结果副标题会标注“历史”。按回车用默认浏览器打开。

  3. 3
    取消历史记录

    进入“设置 → 插件 → 书签与历史记录”，关闭“搜索历史记录”；也可单独关闭某个浏览器。

11

WEB SEARCH

浏览器引擎

怎么使用

在全局搜索中输入关键词，选择“用 Google / Bing / GitHub 搜索”并回车，即可在默认浏览器中打开结果。

输入MyTools→用 GitHub 搜索

怎么添加

进入“设置 → 插件 → 搜索引擎”，新增名称和 URL。用 {query} 标记关键词插入位置。

示例 · DuckDuckGo
https://duckduckgo.com/?q={query}
一个引擎打开多个地址

URL 输入框支持每行一个地址。执行一次搜索时，可同时打开多个目标页面。

QUICK TEXT

快捷文本

把邮箱、地址、回复模板等高频文字保存成快捷文本。搜索触发词后回车，内容会复制并粘贴到此前聚焦的窗口。

添加短语

  1. 1
    打开插件设置

    进入“设置 → 插件 → 快捷文本”。

  2. 2
    新增一行

    触发词填写 email，短语内容填写你的邮箱。

  3. 3
    保存

    回到目标输入框准备调用。

使用短语

  1. 1
    唤起搜索

    按 Alt + Space。

  2. 2
    输入触发词

    输入 email 找到刚添加的短语。

  3. 3
    粘贴

    按回车，内容自动进入原来的窗口。

13

TRANSLATION

翻译插件

使用默认热键 Alt + C 或别名 ff 打开翻译。当前主要支持中文与英文互译。

译

翻译

粘贴文本后自动识别中英文。实时模式边输入边翻译；手动模式按 Ctrl + Enter。

☆

收藏

在翻译结果旁点击收藏按钮，保存需要反复查看的词语或句子。

★

查看收藏

切换到“收藏”列表，浏览已保存项目，也可以重新翻译或删除。

↶

历史列表

打开“历史记录”查看最近翻译，并快速回到某一次输入和结果。

15

BUILD WITH AI

使用 AI 创建插件

“创建插件”提供 AI 创建、修改和删除开发插件的界面。开始前，需要先配置 DeepSeek API Key。

!

前置条件：设置环境变量

在 PowerShell 中运行下面的命令，把示例值替换成自己的 Key，然后彻底退出并重新启动 MyTools。

PowerShell
[Environment]::SetEnvironmentVariable(
  "DEEPSEEK_API_KEY",
  "你的 DeepSeek API Key",
  "User"
)
保护你的 Key

不要把真实 API Key 放进截图、文档或 Git 提交。如果界面仍提示缺少 Key，请先从托盘彻底退出 MyTools，再重新打开。

新建、修改与删除

＋

新建插件

用默认热键 Alt + X 或输入 create 打开“创建插件”，选择“自动创建”，描述需求后发送。

✎

修改插件

在右侧列表选中已有开发插件，确认界面显示“当前选中插件”，再描述需要调整的内容。

×

删除插件

选择目标开发插件，点击删除并确认。删除前先确认没有需要保留的代码或配置。

实际演示：逐步完善天气插件

CASE 01

创建基础天气查询

目标：输入城市查询天气；不出现在全局搜索中；别名为 tq。

可以直接发送给 AI

创建一个天气查询插件。用户输入城市名称后，查询并显示该城市的当前天气。插件不要出现在全局搜索结果中，别名设置为 tq。

完成后验证输入 tq 上海 能返回天气只输入“上海”时不出现该插件结果
CASE 02

支持当前城市

先在右侧选中刚创建的天气插件，再继续对话。

修改提示词

我希望默认查询自己当前城市的天气；如果用户指定了城市，就查询用户输入的城市。

完成后验证输入 tq 查询当前位置城市输入 tq 北京 时以北京为准
CASE 03

增加默认城市配置

继续选中同一个插件，让 AI 新增一个可编辑的配置项。

修改提示词

给这个插件增加一个文本输入类型的配置项，用来设置我自己的城市。没有在搜索中指定城市时，优先使用这个配置值；配置为空时再获取当前城市。

完成后验证插件设置中出现“我的城市”文本框保存城市后，输入 tq 默认查询该城市
修改后没有马上生效？

点击“全部刷新”。如果 AI 自动安装依赖或启动 watch 失败，打开插件目录，按界面提示运行 npm install 和 npm run watch，再回到 MyTools 刷新。
