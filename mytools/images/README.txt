MyTools 用户手册截图清单
========================

把截图放在本目录并使用下列文件名，页面会自动用截图替换对应占位框。
建议使用 PNG，内容区截图推荐 16:9（例如 1600 × 900），尽量隐藏 API Key、用户名等隐私信息。

04-general-settings.png        搜索热键、界面语言、主题
05-plugin-settings.png         插件热键、Alias、启用、Global
06-mouse-gestures.png          手势轨迹与新增手势设置
07-uuid.png                    guid 与 guid 10 的结果
08-clipboard.png               搜索、纯文本粘贴、连续粘贴

13-translator.png              翻译、收藏与历史
